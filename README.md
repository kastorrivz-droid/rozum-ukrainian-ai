# Rosum OS Knowledge Pack

Актуальный рабочий снимок проекта **Rosum OS / ROZUM_AI_v2.1**.

Начальная точка чтения: [`00_MASTER_INDEX.md`](00_MASTER_INDEX.md).

Пакет содержит:

- 15 канонических модулей Knowledge Pack;
- строгую JSON Schema для конверта протокола v2.1;
- криптографический комплект `CVT-001` без изменения исходных байтов;
- ненормативную концептуальную записку о двухконтурном мышлении.

Главное правило: документы `LOCKED`, подтверждённые тесты и черновые гипотезы не смешиваются. Изменение нормативного слоя требует записи в `12_DECISIONS_LOG.md` и повторной проверки затронутых тестов.
