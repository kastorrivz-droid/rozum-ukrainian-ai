# ROZUM Ukrainian AI — GitHub Pages

Цей комплект НЕ замінює поточний README, Python-код або документи ROZUM OS.

Репозиторій: https://github.com/kastorrivz-droid/rozum-ukrainian-ai

1. Розпакуйте ZIP на компʼютері.
2. У репозиторії відкрийте Add file → Upload files.
3. Додайте всі файли й папку assets/ до кореня гілки main. Не завантажуйте сам ZIP як є. За потреби відкрийте папку assets/ окремо й переконайтеся, що вона збережена з правильною структурою.
4. Підтвердіть Commit changes.
5. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
6. Перевірте https://kastorrivz-droid.github.io/rozum-ukrainian-ai/ після публікації.

Важливо: зміст сайта публічний. Не додавайте в репозиторій приватні ключі або особисті дані.
