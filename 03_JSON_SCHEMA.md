# 03 — JSON Schema

**Status:** VALIDATED / STRUCTURAL BASELINE  
**Schema dialect:** JSON Schema 2020-12

## Источник

Машиночитаемая схема находится в `schemas/ROZUM_AI_v2.1.schema.json`.

## Структурные гарантии

Схема проверяет:

- точные значения `protocol` и `protocol_version`;
- наличие обязательных полей;
- формат UUID для `id` и ненулевого `reply_to`;
- UTC timestamp с суффиксом `Z`;
- непустые `sender_id`, `key_id`, `author.id`, `author.role`, `intent` и `output_format`;
- объектные типы `context`, `context.state` и `data`;
- `signature` как Base64-строку или `null`.

## Граница ответственности

JSON Schema не доказывает:

- что UUID ранее не использовался;
- что timestamp находится в допустимом временном окне;
- что `sender_id` имеет право использовать `key_id`;
- что Base64 декодируется в правильную длину подписи конкретного профиля;
- что подпись математически верна;
- что `reply_to` ссылается на известное сообщение;
- что семантика `data` допустима для конкретного `intent`.

Эти проверки выполняются на стадиях Semantic, Replay и Crypto.

## Правило расширения

Новые верхнеуровневые поля добавляются только через версионированное решение. Данные конкретной задачи размещаются в `data`, а переносимый контекст — в `context`.
